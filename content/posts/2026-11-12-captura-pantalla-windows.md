La forma más rápida de hacer una captura de pantalla en Windows es pulsar **Windows + Mayús + S**: la pantalla se oscurece y eliges si quieres capturar una zona, una ventana o toda la pantalla. La imagen se copia al portapapeles, así que puedes pegarla directamente con **Ctrl + V** en WhatsApp, un correo o un documento.

Pero hay más métodos, y cada uno es mejor para algo distinto. Te los explicamos todos.

## 1. Windows + Mayús + S: el más práctico

1. Pulsa a la vez **Windows + Mayús + S**.
2. Arriba aparece una pequeña barra con modos: **rectangular**, **forma libre**, **ventana** y **pantalla completa**.
3. Selecciona la zona con el ratón.
4. La captura se copia al portapapeles y aparece una notificación abajo a la derecha. Si haces clic en ella, se abre en la Herramienta Recortes para dibujar, recortar o guardarla.

Es el método que recomendamos para el día a día.

## 2. Impr Pant: toda la pantalla de un toque

La tecla **Impr Pant** (puede aparecer como *ImpPnt*, *PrtSc* o *Print Screen*) está arriba a la derecha del teclado.

- **Impr Pant:** copia toda la pantalla al portapapeles. En Windows 11 actualizado, esta tecla suele abrir directamente la Herramienta Recortes; puedes cambiarlo en **Configuración › Accesibilidad › Teclado**.
- **Alt + Impr Pant:** copia solo la ventana activa, sin el resto del escritorio.

En portátiles, a veces hay que pulsar también la tecla **Fn** (por ejemplo, **Fn + Impr Pant**).

## 3. Windows + Impr Pant: guardar automáticamente

Si quieres que la captura se guarde sola como archivo, pulsa **Windows + Impr Pant**. La pantalla parpadea un instante y la imagen se guarda en:

**Imágenes › Capturas de pantalla**

Es perfecto si vas a hacer muchas capturas seguidas y no quieres ir pegándolas una a una.

## 4. Herramienta Recortes: con temporizador y edición

Búscala escribiendo **Recortes** en el menú Inicio. Además de capturar, permite:

- **Retrasar la captura** 3, 5 o 10 segundos, ideal para capturar menús desplegables que se cierran al pulsar una tecla.
- **Dibujar y resaltar** con lápiz o rotulador, y recortar.
- **Grabar la pantalla en vídeo** en Windows 11 (botón de la cámara de vídeo).
- **Extraer texto** de la imagen en versiones recientes, muy útil para copiar texto de una foto o un PDF escaneado.

## 5. Captura de una página web completa (con scroll)

Windows no captura páginas largas por sí solo, pero los navegadores sí:

- **Microsoft Edge:** pulsa **Ctrl + Mayús + S** y elige **Capturar página completa**.
- **Google Chrome:** pulsa **F12** para abrir las herramientas de desarrollador, luego **Ctrl + Mayús + P**, escribe *screenshot* y elige **Capture full size screenshot**.
- **Firefox:** clic derecho en la página › **Hacer captura de pantalla** › **Guardar página completa**.

## Resumen de atajos

| Atajo | Qué hace | Dónde va |
|---|---|---|
| Windows + Mayús + S | Captura una zona, ventana o pantalla | Portapapeles (y Recortes) |
| Impr Pant | Pantalla completa | Portapapeles o Recortes |
| Alt + Impr Pant | Solo la ventana activa | Portapapeles |
| Windows + Impr Pant | Pantalla completa | Imágenes › Capturas de pantalla |
| Ctrl + Mayús + S (Edge) | Página web completa | Archivo |

## ¿Dónde se guardan las capturas?

- Las hechas con **Windows + Impr Pant**: en **Imágenes › Capturas de pantalla**.
- Las de la **Herramienta Recortes**: en Windows 11 se guardan automáticamente en esa misma carpeta, salvo que lo desactives en los ajustes de Recortes.
- Las que solo se copian al **portapapeles**: no se guardan como archivo hasta que las pegas en algún sitio. Pulsa **Windows + V** para ver el historial del portapapeles (tienes que activarlo la primera vez).

## Consejo: pega directamente en WhatsApp Web

No hace falta guardar la captura. Haz **Windows + Mayús + S**, abre el chat en WhatsApp Web o en la app de escritorio y pulsa **Ctrl + V**. Te ahorras buscar el archivo.

## Error común que debes evitar

Compartir capturas sin revisar lo que se ve. Es fácil enviar sin querer pestañas abiertas, notificaciones con mensajes privados o datos personales. Usa el modo rectangular para capturar solo lo necesario, o tapa la información sensible con la Herramienta Recortes antes de enviarla.

## Preguntas frecuentes

### ¿Por qué no funciona la tecla Impr Pant?
En portátiles puede que necesites pulsar **Fn** a la vez. También puede que algún programa (como OneDrive o Dropbox) haya tomado el control de la tecla; revisa sus ajustes.

### ¿Cómo hago una captura en un Mac?
Pulsa **Cmd + Mayús + 4** para seleccionar una zona o **Cmd + Mayús + 3** para toda la pantalla. **Cmd + Mayús + 5** abre todas las opciones, incluida la grabación de pantalla.

### ¿Puedo hacer capturas con retraso?
Sí, con la Herramienta Recortes puedes programar un retraso de 3, 5 o 10 segundos.

### ¿Cómo capturo solo una ventana sin el fondo?
Pulsa **Alt + Impr Pant** con esa ventana seleccionada, o usa el modo **Ventana** de Windows + Mayús + S.
