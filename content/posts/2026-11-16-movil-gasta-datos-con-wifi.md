Si tu móvil gasta datos aunque estés conectado al wifi, lo más probable es que tenga activado el **cambio automático a datos móviles**: cuando el wifi va lento o se corta un momento, el móvil usa los datos para no dejarte sin conexión. En iPhone se llama **Asistencia para Wi-Fi** y en Android suele aparecer como **Cambiar a datos móviles** o **Wi-Fi inteligente**.

Desactivándolo y revisando un par de ajustes más, dejarás de llevarte sorpresas en la factura.

## 1. Desactiva el cambio automático a datos

### En iPhone
1. Ve a **Ajustes › Datos móviles** (o Móvil).
2. Baja hasta el final de la lista de apps.
3. Desactiva **Asistencia para Wi-Fi**.

Justo debajo verás cuántos datos ha consumido esta función. Muchas personas se sorprenden.

### En Android
La ruta cambia según la marca:
- **Samsung:** Ajustes › Conexiones › Wi-Fi › tres puntos › **Intelligent Wi-Fi** › desactiva **Cambiar a datos móviles**.
- **Google Pixel y otros:** Ajustes › Redes e internet › Internet › Preferencias de red › desactiva **Cambiar automáticamente a datos móviles** (si aparece).
- **Xiaomi:** Ajustes › Wi-Fi › Asistente de Wi-Fi › desactiva el cambio a datos.

## 2. Comprueba que el wifi funciona de verdad

A veces el móvil está «conectado» al wifi, pero ese wifi **no tiene internet** (el router se ha colgado, o es un wifi público que pide registrarse). Entonces el móvil usa los datos sin avisar.

- Abre una web con los datos móviles **desactivados**. Si no carga, el problema es el wifi.
- **Reinicia el router** desenchufándolo 30 segundos.
- En wifis públicos, abre el navegador para completar la página de acceso.

## 3. Mira qué apps consumen datos

- **iPhone:** Ajustes › Datos móviles. Verás el consumo de cada app y puedes desactivar los datos para las que no los necesiten.
- **Android:** Ajustes › Conexiones (o Redes e internet) › **Uso de datos** › Uso de datos móviles.

Las que más suelen consumir son las redes sociales con vídeos (TikTok, Instagram, YouTube), las apps de música y las copias de seguridad de fotos.

## 4. Limita las copias de seguridad y actualizaciones a wifi

- **Google Fotos:** Ajustes de copia de seguridad › **Uso de datos móviles** › sin datos.
- **iCloud Fotos:** Ajustes › Apps › Fotos › **Datos móviles** › desactívalo.
- **WhatsApp:** Ajustes › Almacenamiento y datos › **Descarga automática** › Con datos móviles › solo fotos (o nada).
- **Tienda de apps:** configura las actualizaciones automáticas **solo con wifi** (Google Play: Ajustes › Preferencias de red; App Store: Ajustes › App Store › Datos móviles).

## 5. Activa el ahorro de datos

- **Android:** Ajustes › Conexiones › Uso de datos › **Ahorro de datos**. Limita el consumo en segundo plano.
- **iPhone:** Ajustes › Datos móviles › Opciones › **Modo de datos reducidos**.

Puedes activarlo de forma permanente si tu tarifa tiene pocos gigas.

## Resumen de causas y soluciones

| Causa | Solución |
|---|---|
| Asistencia para Wi-Fi o cambio automático | Desactívalo |
| Wifi conectado pero sin internet | Reinicia el router |
| Apps en segundo plano | Restringe sus datos |
| Copias de seguridad de fotos | Solo con wifi |
| Descarga automática de WhatsApp | Desactívala con datos |
| Llamadas por wifi desactivadas | Actívalas si tu operadora lo permite |

## Consejo: pon un límite de datos

En Android puedes fijar un **aviso y un límite de datos** mensual en Ajustes › Uso de datos › **Ciclo de facturación**. El móvil te avisará cuando te acerques al límite de tu tarifa y puede cortar los datos al alcanzarlo.

## Error común que debes evitar

Desactivar los datos móviles por completo para «ahorrar» y olvidarte de volver a activarlos. Te quedarás sin WhatsApp ni mapas al salir de casa. Es mucho mejor controlar qué apps pueden usarlos.

## Preguntas frecuentes

### ¿El móvil gasta datos si el wifi está activado pero sin conexión?
Sí, si tiene activado el cambio automático a datos móviles.

### ¿Usar el móvil como punto de acceso gasta mis datos?
Sí. Todo lo que hagan los dispositivos conectados a tu móvil consume tus datos.

### ¿Las llamadas por WhatsApp con wifi gastan datos?
No, si el wifi funciona. Si el wifi falla y tienes el cambio automático activado, pasarán a usar datos.

### ¿Cuántos datos gasta ver vídeos?
Mucho: una hora de vídeo en calidad alta puede superar 1 o 2 GB. Baja la calidad en los ajustes de YouTube o Netflix cuando uses datos.
